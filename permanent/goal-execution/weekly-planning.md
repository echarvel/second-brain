At the end or beginning of each week, set aside some time to review last week's performance and plan the upcoming week's tasks. For each quarterly goal, we identify the highest daily and weekly actions that must take to move the goal forward. We then shuffle the existing weekly tasks as some may need to be bumped to a different week. In a perfect week, no shuffling of tasks is needed.
