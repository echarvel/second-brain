# Google search drops cache link from search results (highlights)

- Author:: #croes
- Full Title:: Google search drops cache link from search results
- Category:: #articles
- Summary:: Google has removed the cache link from its search results page after a period of testing. The cache button is no longer visible when clicking on the three dots for more information on a search result snippet. However, users can still access the cache by searching for [cache:domain.com] in Google. It is unclear whether this change is permanent or if it is part of a test group.
